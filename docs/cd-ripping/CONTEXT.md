# CD ripping and library import

The workflow from a physical audio CD to an album in the user's music collection.

## Language

**Rip**:
Audio extracted from one physical CD.
A rip is not yet necessarily an accepted library album.

**Incoming album**:
A completed rip waiting for classification, review, or acceptance into the music library.
_Avoid_: Library album, when referring to unreviewed output

**Inbox**:
Temporary, disposable storage for rips awaiting library import, which may include incomplete transfers or rerips replacing earlier contents.
An inbox copy is not a backup or an accepted library album.

**Ownership category**:
Whether the physical CD associated with an album is owned by the user or borrowed.
It is independent of the album's title, release identity, and artwork.

**Loaner**:
A borrowed CD, or the ownership category of an album obtained from one.

**Library album**:
An album accepted into the user's organized music collection.
